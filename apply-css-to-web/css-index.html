Introducción a CSS

Dando formato al HTML

CSS permite añadir fuentes, tamaños, bordes, paddings, diseño del layout, diseño responsivo y animaciones, entre otras muchas cosas.

En este texto hemos colocado una etiqueta de style dentro de la etiqueta <h3>

Se puede apreciar que el texto inicial esta en color azul. Esto es porque hemos incluido una etiqueta <style> dentro de la etiqueta <head> del documento HTML. En ella hemos indicado que todos los elementos <h1> deben mostrarse en color azul.

De la misma manera podemos apreciar que las etiquetas <h2> estan en verde. Es por la misma razón, pero en este caso esta en un fichero style.css dentro de la carpeta styles que hemos enlazado en la etiqueta <link> del <head> del documento HTML.
