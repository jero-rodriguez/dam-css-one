Propiedades de los bordes en CSS

En CSS, las propiedades de los bordes permiten controlar el estilo, el grosor y el color de los bordes de los elementos HTML. A continuación, se describen algunas de las propiedades más comunes relacionadas con los bordes:

  • border-width: Define el grosor del borde. Puede especificarse en unidades como píxeles (px), em, rem, etc. Ejemplo: border-width: 2px;
  • border-style: Define el estilo del borde. Los valores comunes incluyen solid, dashed, dotted, double, groove, entre otros. Ejemplo: border-style: dashed;
  • border-color: Define el color del borde. Puede especificarse utilizando nombres de colores, valores hexadecimales, RGB, RGBA, HSL, etc. Ejemplo: border-color: #ff0000;
  • border-radius: Permite redondear las esquinas del borde. Se puede especificar en píxeles o porcentajes. Ejemplo: border-radius: 10px;
  • border: Es una propiedad abreviada que combina las propiedades de ancho, estilo y color del borde en una sola declaración. Ejemplo: border: 2px solid #0000ff;

Estas propiedades pueden aplicarse a cualquier elemento HTML para mejorar la apariencia visual y destacar secciones específicas de una página web.
