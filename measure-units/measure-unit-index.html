Unidades de Medida en CSS

A diferencia de HTML en CSS se puede indicar el tamaño de los elementos con distintas unidades de medida. Las unidades más comunes son:

  • px: píxeles. Unidad absoluta.
  • em: unidades relativas al tamaño de la fuente del elemento padre.
  • rem: unidades relativas al tamaño de la fuente del elemento raíz (html).
  • %: porcentaje relativo al tamaño del elemento padre.
