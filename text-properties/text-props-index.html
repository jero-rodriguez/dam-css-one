Propiedades de los textos en CSS

En esta sección vamos a investigar algunas propiedades que tienen los textos. Lo que hemos hecho es, en lugar de crear N clases para cada propiedad, vamos a crear una para el parrafo y, a continuación, aplicaremos el formato adecuado con una clase. Hemos colocado las clases en el fichero CSS para mantener el codigo limpio.

Cambios en el color

En este párrafo hemos cambiado el color del texto a verde claro usando la propiedad color de CSS.

Texto Decorado

En este párrafo hemos decorado el texto con una linea de color azul discontinua usando la propiedad text-decoration de CSS.

Texto Indentado

En este párrafo hemos indentado el texto 30 pixeles usando la propiedad text-indent de CSS.

Texto Alineado

En este párrafo hemos alineado el texto al centro usando la propiedad text-align de CSS.

Texto Transformado

En este párrafo hemos transformado el texto a mayusculas usando la propiedad text-transform de CSS.

Letras Espaciadas

En este párrafo hemos espaciado las letras 2 pixeles y las palabras 5 pixeles usando la propiedad letter-spacing de CSS.

Alto de línea

En este párrafo hemos cambiado el alto de línea usando la propiedad line-height de CSS.

Se puede comprobar introduciendo un segundo parrafo con la misma clase.

En este párrafo hemos añadido una sombra al texto usando la propiedad text-shadow de CSS.
